# Frontend design contract

Tool Relay is a physical workshop pegboard, not a dashboard. The first viewport is split into a service rail, a perforated wall of tool silhouettes, and a paper custody docket. Graphite, galvanized gray, safety orange, inspection teal, and chalk white are the only dominant colors. Components use punched tags, inspection stamps, tool silhouettes, and hard steel edges. Motion consists of a scanning inspection beam, tool lift, tag slide, latch close, and quarantine stripe; reduced-motion mode removes it. The core action is pulling a known tool tag and sending a job-fit plan through validator consensus. A separate return bench makes the two-phase lifecycle visible.

The UI must never become a generic card grid, marketing hero, map, stage, dinner plan, or radial instrument. Wallet connection, read state, checkout write, return write, pending feedback, and errors remain visible on narrow screens.
